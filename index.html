2. Enterprise Wi-Fi Router / AP Configuration SOP-NET-02

• Operating Mode: Set to Access Point (AP) Mode (disable internal DHCP server to prevent IP conflicts with the core gateway).

ANSI/TIA-568-B Structured Cabling Pinout & Wire Standards

Cat6 UTP cable termination standards for RJ45 keystones and patch panels

T568B Wire Sequence (Industry Standard) Pins 1 to 8
Pin 1: White/Orange TX+
Pin 2: Solid Orange TX-
Pin 3: White/Green RX+
Pin 4: Solid Blue Bi-directional
Pin 5: White/Blue Bi-directional
Pin 6: Solid Green RX-
Pin 7: White/Brown Power / Ground
Pin 8: Solid Brown Power / Ground

Layer 1 Quality Assurance Verification

Every terminated cable must pass physical validation with an RJ45 continuity tester:

  • Straight Sequence: LEDs 1 through 8 must flash consecutively on both master and remote units.
  • Open Circuit: Any unlit LED indicates a broken conductor or unseated blade in the connector.
  • Short Circuit / Cross: Irregular blinking indicates swapped pinout (e.g. Pin 3 and Pin 5 crossed).
  • Optical Power Check: Measure optical input at media converter SC connector; acceptable sensitivity threshold is -8 dBm to -24 dBm.

Incident Report: Uplink Flapping & High Packet Drop Analysis

Real-world troubleshooting scenario resolved during office network maintenance

Incident ID: INC-HW-2026-031
Failure Type: Link Flapping (L1/L2)
Downtime: Intermittent (~18 mins)
Root Cause: Defective RJ45 Patch Pin

1. Defect Description

Core router reported interface `Gig0/0` flapping every 40-90 seconds. Switch ports showed CRC errors and media converter TX LED was intermittently turning off.

2. Root Cause Analysis

Testing with cable analyzer showed Pin 3 (RX+) in the Cat6 patch cord between media converter and router had an intermittent open connection when physically moved, causing carrier loss.

3. Preventive Measure & Resolution

Replaced the unbranded patch cord with a factory-molded Cat6 shielded patch cable. Secured the media converter with strain relief brackets. Link stability reached 100% with 0 CRC drops over 48 hours.
